# Sagasu 使い方ガイド

Sagasu（探す）の基本的な使い方をまとめたガイドです。概要とインストール方法は [README](../README.md) を参照してください。

## 1. 起動と検索

1. `Alt+Space`（既定値）を押して、ランチャーを開きます。
2. 検索語を入力すると、ファイル名と本文（対応形式）から結果がすぐに表示されます。

ひらがなとカタカナ、全角と半角、大文字と小文字は区別せずに探します。たとえば `みつもり` や `mitsumori`（ローマ字）で「ミツモリ」「ﾐﾂﾓﾘ」を含むファイルが見つかります。漢字の読み（`けいり` → 「経理」）には対応していないため、漢字の名前は漢字で入力してください。

フォルダ名とファイル名の言葉を組み合わせることもできます。`経理 請求` は「経理」フォルダの中の「請求」を含むファイルを上位に出します。少し打ち間違えても（例: `rprt` → `report`）候補に出ます。

### AIで探す（文章で探す）

名前を思い出せないときは、検索欄右の「AIで探す」（`Ctrl+I`）に切り替えて、文章で入力して `Enter` を押します。

- 例:「去年A社に出した保守費用の見積もり」「先月の引っ越しの見積もりPDF」
- AI が「名前に入っていそうな言葉」「中身に書いてありそうな言葉」「種類」「期間」に分け、パソコン内のインデックスから探します。どう解釈したかは結果の上に表示されます。
- AI に送るのは入力した文章だけです。ファイル名や中身は送りません。

## 2. 検索構文

検索語と絞り込み条件はスペースで区切って同時に指定できます。

| 構文 | 意味 | 例 |
| --- | --- | --- |
| `ext:拡張子` | 指定した拡張子のファイルに絞る | `ext:pdf` |
| `in:フォルダ名` | 指定したフォルダ名の中にあるファイルに絞る | `in:経理` |
| `after:YYYY-MM-DD` | 指定日以降に更新されたファイルに絞る | `after:2026-01-01` |
| `before:YYYY-MM-DD` | 指定日以前に更新されたファイルに絞る | `before:2026-06-30` |
| `size>数値mb` | 指定サイズより大きいファイルに絞る | `size>10mb` |

### 日付語

`after:` や `before:` の代わりに、次の日付語を使えます。

| 日付語 | 意味 |
| --- | --- |
| 今日 | 今日 |
| 昨日 | 昨日 |
| 今週 | 今週 |
| 先週 | 先週 |
| 今月 | 今月 |
| 先月 | 先月 |
| 今年 | 今年 |
| 去年 | 去年 |

### 検索例

- `請求書 ext:pdf 先月`: 先月更新された PDF のうち、「請求書」を含むもの
- `見積 in:営業 ext:xlsx`: 「営業」フォルダ内の Excel ファイルのうち、「見積」を含むもの
- `議事録 after:2026-01-01`: 2026 年 1 月 1 日以降の「議事録」
- `動画 size>100mb`: 100 MB より大きい動画ファイル（`動画` `画像` `写真` `エクセル` `パワポ` などは種類の指定になります）
- `経理 type:folder`: 名前に「経理」を含むフォルダだけ
- `契約 ext:docx 今年`: 今年更新された Word 文書のうち、「契約」を含むもの

## 3. ピン留めとエイリアス

よく開くフォルダはピン留めできます。

エイリアスを設定すると、短い言葉（例: `経理`）を入力するだけで、対応するフォルダへ直接移動できます。覚えやすい短い言葉にしておくと便利です（例: 「経理」「提出」「写真」）。

## 4. AI で整理する

散らかったフォルダを、指示の言葉で整理できます。

### 流れ

1. 整理したいフォルダを指定します。
2. 指示を入力します。
3. 移動前後の計画をプレビューで確認します。
4. 内容に問題がなければ承認します。承認すると、ファイルが移動されます。

計画を承認しなければ、ファイルは一切動きません。

### 指示の例

- 「種類別に整理して」: 拡張子や種類ごとにフォルダを分けます（例: 文書、画像、表計算）。
- 「年ごとに整理して」: 更新日の年でフォルダを分けます。
- 「年月ごとにまとめて」: `2026\03` のように年と月のフォルダに分けます。
- 「請求書だけ別フォルダにまとめて」: 名前に「請求書」を含むファイルをまとめます。

AI を使わず、「種類別」「年月別」のルールプリセットで整理することもできます。この場合、API キーは不要です。

### 安全のための仕組み

- ファイルは削除されず、移動のみです。
- 同じ名前のファイルがある場合は上書きせず、リネームして移動します。
- `C:\Windows`、`C:\Program Files`、`AppData` などのシステムフォルダは整理対象になりません。

## 5. 取り消し

整理操作はすべて「履歴」タブに残ります。各整理の「元に戻す」を押すと、移動したファイルを元の場所へ戻します。整理で新しく作られ、空になったフォルダは片付けます（中にファイルが残っているフォルダは消しません）。元の場所に同じ名前のファイルができていた場合は、上書きせず「名前 (2)」のように戻します。

### 重複ファイルを探す

「整理」タブの下にある「重複ファイルを探す」で、中身がまったく同じファイルを探せます。上のフォルダ欄が空なら検索する場所すべて、入っていればそのフォルダの中だけが対象です。不要なコピーは「ごみ箱へ」で移動できます（各組の最後の1つは移動できません）。ごみ箱から元に戻せます。

## 6. 設定

設定画面で次の項目を変更できます。

### 検索場所

- OneDrive、NAS（ネットワークドライブ）、外付けドライブを検索場所として追加できます。

### 除外

- 検索から除外するフォルダを指定できます。

### ホットキー

- ランチャーを開くキーを変更できます。既定値は `Alt+Space` です。
- 他のアプリと衝突する場合は、別の組み合わせに変更してください。

### AI 機能

- Anthropic API キーを貼り付けると、自然文検索と AI による整理提案が使えるようになります。
- API キーは取得方法を [Anthropic Console](https://console.anthropic.com/) で確認できます。
- API キーは Windows 資格情報マネージャーに保存されます。
- AI 機能を使う場合のみ、AI に送信されます。「AIで探す」では入力した文章だけ、「AI整理」では対象フォルダ内のファイル名・場所・日付・サイズを送ります。ファイルの中身は送信しません。
- モデルは Claude Opus 5.5（既定）・Sonnet 5.5・Haiku 5.5 から選べます。料金は Anthropic の API 利用料として APIキーの持ち主に請求されます。
- AI 機能を使わない場合、API キーは未設定のままで構いません。

## 7. データの保存場所

- 検索インデックス: `%APPDATA%\jp.sagasu.app`
- API キー: Windows 資格情報マネージャー
