# Sagasu 使い方ガイド

Sagasu（探す）の基本的な使い方をまとめたガイドです。概要とインストール方法は [README](../README.md) を参照してください。

## 1. 起動と検索

1. `Alt+Space`（既定値）を押して、ランチャーを開きます。
2. 検索語を入力すると、ファイル名と本文（対応形式）から結果がすぐに表示されます。

ひらがなとカタカナ、全角と半角、大文字と小文字は区別せずに探します。たとえば `みつもり` や `mitsumori`（ローマ字）で「ミツモリ」「ﾐﾂﾓﾘ」を含むファイルが見つかります。

漢字の名前も、読みで探せます（`けいり` → 「経理」）。くわしくは [3. 読みで探す](#3-読みで探す) を参照してください。

フォルダ名とファイル名の言葉を組み合わせることもできます。`経理 請求` は「経理」フォルダの中の「請求」を含むファイルを上位に出します。少し打ち間違えても（例: `rprt` → `report`）候補に出ます。

1 文字だけの検索は、ファイル名だけを対象にします。

## 2. 検索構文

検索語と絞り込み条件はスペースで区切って同時に指定できます。

| 構文 | 意味 | 例 |
| --- | --- | --- |
| `ext:拡張子` | 指定した拡張子のファイルに絞る | `ext:pdf` |
| `in:フォルダ名` | 指定したフォルダ名の中にあるファイルに絞る | `in:経理` |
| `after:YYYY-MM-DD` | 指定日以降に更新されたファイルに絞る | `after:2026-01-01` |
| `before:YYYY-MM-DD` | 指定日以前に更新されたファイルに絞る | `before:2026-06-30` |
| `size>数値mb` | 指定サイズより大きいファイルに絞る | `size>10mb` |

### 日付語

`after:` や `before:` の代わりに、次の日付語を使えます。

| 日付語 | 意味 |
| --- | --- |
| 今日 | 今日 |
| 昨日 | 昨日 |
| 今週 | 今週 |
| 先週 | 先週 |
| 今月 | 今月 |
| 先月 | 先月 |
| 今年 | 今年 |
| 去年 | 去年 |

### 検索例

- `請求書 ext:pdf 先月`: 先月更新された PDF のうち、「請求書」を含むもの
- `見積 in:営業 ext:xlsx`: 「営業」フォルダ内の Excel ファイルのうち、「見積」を含むもの
- `議事録 after:2026-01-01`: 2026 年 1 月 1 日以降の「議事録」
- `動画 size>100mb`: 100 MB より大きい動画ファイル（`動画` `画像` `写真` `エクセル` `パワポ` などは種類の指定になります）
- `経理 type:folder`: 名前に「経理」を含むフォルダだけ
- `契約 ext:docx 今年`: 今年更新された Word 文書のうち、「契約」を含むもの

## 3. 読みで探す

ひらがなで打つと、漢字の名前のファイルやフォルダも見つかります。ローマ字で打った場合も、かなに変換して探します。

| 打つ言葉 | 見つかるもの |
| --- | --- |
| `けいり` | 「経理」 |
| `みつもり` | 「見積書.docx」 |

- 漢字の読みは、Windows の日本語入力（MS-IME）を使って取得します。Windows の日本語入力が使える環境でのみ動きます。
- 最初のスキャンのあと、読みはバックグラウンドで準備されます。画面下のステータスバーに「読みを準備中 x / y」と表示されている間は、まだ見つからないものがあることがあります。準備した読みは保存されるため、次回からも使えます。
- 漢字で入力した検索は、これまでどおり動きます。

## 4. 絞り込みボタン

検索欄の下に、ボタンが 2 段並んでいます。ボタンを押すと、その条件で絞り込めます。

| 段 | ボタン |
| --- | --- |
| 種類 | すべて / 文書 / PDF / 表計算 / スライド / 画像 / 動画 / 音楽 / フォルダ |
| 期間 | いつでも / 今日 / 今週 / 今月 / 今年 / 去年 |

- 言葉を打たなくても使えます。たとえば検索欄を空にして「画像」と「今週」を選ぶと、今週更新された画像の一覧が出ます。
- 言葉を打っているときは、その言葉に加えて絞り込まれます。

## 5. 画像の中の文字を探す

スクリーンショットやスキャンした画像（png、jpg、jpeg、bmp、gif、tif、tiff）は、写っている文字も検索できます。たとえば「振込」と打つと、「振込先口座」と写ったスクリーンショットが見つかります。

- 文字の認識には、Windows に入っている文字認識（OCR）を使います。無料で、インターネットに接続せずに動きます。
- 検索結果を選ぶと、プレビューに画像そのものと、認識された文字が表示されます。
- 文字の認識は完璧ではありません。読み間違いがあることがあります。
- この機能は既定でオンです。オフにするには、設定の「中身の検索」で変更します（[12. 設定](#12-設定) を参照）。

## 6. 検索履歴

検索欄が空のとき、「最近の検索」に直近の検索語が最大 12 件並びます。ボタンを押すと、その検索をやり直せます。「履歴を消す」を押すと、一覧を消せます。

- 検索履歴に残るのは、検索のあとにファイルを開いたときの検索語だけです。
- 検索履歴はこのパソコンの中だけに保存されます。

## 7. ピン留めとエイリアス

よく開くフォルダはピン留めできます。

エイリアスを設定すると、短い言葉（例: `経理`）を入力するだけで、対応するフォルダへ直接移動できます。覚えやすい短い言葉にしておくと便利です（例: 「経理」「提出」「写真」）。

## 8. フォルダを整理する

散らかったフォルダを、プリセットのルールで整理できます。

### 流れ

1. 整理したいフォルダを指定します。
2. 整理のしかた（プリセット）を選びます。
3. 移動前後の計画をプレビューで確認します。
4. 内容に問題がなければ承認します。承認すると、ファイルが移動されます。

計画を承認しなければ、ファイルは一切動きません。

### プリセット

- 「種類別」: 拡張子や種類ごとにフォルダを分けます（例: 文書、画像、表計算）。
- 「年別」: 更新日の年でフォルダを分けます。
- 「年/月別」: `2026\03` のように年と月のフォルダに分けます。
- 「拡張子別」: 拡張子ごとにフォルダを分けます。

### 安全のための仕組み

- ファイルは削除されず、移動のみです。
- 同じ名前のファイルがある場合は上書きせず、リネームして移動します。
- `C:\Windows`、`C:\Program Files`、`AppData` などのシステムフォルダは整理対象になりません。

## 9. 自動整理ルール

よく行う片付けを「自動整理ルール」として登録しておくと、ファイルが届いたときに自動で移動します。たとえば「ダウンロードに来た PDF を 書類 フォルダへ」といったルールを作れます。

### ルールの動き

- 見張っているフォルダに、条件に合うファイルが直接置かれます。
- そのファイルが 5 秒間変化しなくなったら、移動先へ動かします。ダウンロードが終わってから動くようにするためです。
- ダウンロード途中のファイル（`.crdownload`、`.part`、`.tmp` など）、隠しファイル、Office の一時ファイル（`~$`）は移動しません。
- 同じ名前のファイルがあっても上書きせず、「名前 (2).pdf」のように名前を変えて移動します。
- 自動で移動したものは、すべて「履歴」に「自動整理ルール「名前」」として残ります。「元に戻す」で戻せます。

### ルールの作り方

例：「ダウンロードに来た PDF を 書類 フォルダへ」

1. 「整理」タブの「自動整理ルール」カードで **「ルールを追加」** を押します。
2. **名前** に「PDFは書類へ」など、わかりやすい名前を入力します。
3. **見張るフォルダ** に「ダウンロード」を指定します。
4. **種類** で「PDF」にチェックを入れます。どの種類にもチェックを入れないと、すべての種類が対象になります。
5. **名前に含む言葉** は空欄のままにします。カンマで区切って入力すると、どれか一つを含むファイルが対象になります。空欄なら、名前に関係なく対象になります。
6. **移動先** に「書類」フォルダを指定します。
7. 内容を確かめて、ルールを有効にします。

### 登録したルールの操作

各ルールには次の操作があります。

- **今すぐ実行**: 見張るフォルダにすでにあるファイルを移動します。移動するファイルの一覧を確認してから実行されます。
- **編集**: ルールの内容を変えます。
- **削除**: ルールを消します。
- チェックボックス: オフにすると、ルールは一時的に動かなくなります。

システムフォルダは、見張るフォルダにも移動先にも使えません。別のドライブへの移動にも対応しています（コピーしてサイズを確かめてから、元のファイルを削除します）。

## 10. 大きいファイルを探す

「整理」タブの「大きいファイルを探す」カードには、大きいファイルの上位 100 件が並びます。

- 対象は、整理ページ上部のフォルダ欄に入れたフォルダの中です。フォルダ欄が空なら、検索する場所すべてが対象になります。
- 各ファイルの「場所」ボタンで、保存されている場所をエクスプローラーで開けます。
- 不要なファイルは「ごみ箱へ」で移動できます。ごみ箱から元に戻せます。

## 11. 取り消し

整理操作はすべて「履歴」タブに残ります。各整理の「元に戻す」を押すと、移動したファイルを元の場所へ戻します。整理で新しく作られ、空になったフォルダは片付けます（中にファイルが残っているフォルダは消しません）。元の場所に同じ名前のファイルができていた場合は、上書きせず「名前 (2)」のように戻します。

### 重複ファイルを探す

「整理」タブの下にある「重複ファイルを探す」で、中身がまったく同じファイルを探せます。上のフォルダ欄が空なら検索する場所すべて、入っていればそのフォルダの中だけが対象です。不要なコピーは「ごみ箱へ」で移動できます（各組の最後の 1 つは移動できません）。ごみ箱から元に戻せます。

## 12. 設定

設定画面は次の 5 つのカードで構成されています。

- 検索する場所
- 除外する場所
- 中身の検索
- 呼び出しと起動
- アップデートとサポート

### 検索する場所

- OneDrive、NAS（ネットワークドライブ）、外付けドライブを検索場所として追加できます。

### 除外する場所

- 検索から除外するフォルダを指定できます。

### 中身の検索

- 既定では、Word・Excel・PowerPoint・PDF・テキスト・Markdown・CSV・HTML の中身を検索できます。テキスト系のファイルは、1 ファイルにつき 10 万文字まで取り込みます。
- 「画像（スクリーンショット・スキャン）の中の文字も検索する（Windows の文字認識を使用）」をオンにすると、画像の中の文字も検索できます。既定はオンです（[5. 画像の中の文字を探す](#5-画像の中の文字を探す) を参照）。
- 「プログラムのソースコード・ログ・設定ファイル（.cs .js .json .log など）の中身も検索する」をオンにすると、これらのファイルも対象になります。開発用のフォルダが多いパソコンでは検索用データが大きくなるため、既定はオフです。
- 対象にする最大サイズ（既定 30MB）より大きいファイルの中身は読みません。
- Cドライブ全体（約150万件）を検索する場所に追加しても動きます。ファイル一覧の作成に数十秒、メモリは 420MB 程度を使います。ふだんはユーザーフォルダ（既定）だけで十分です。

### 呼び出しと起動

- ランチャーを開くキーを変更できます。既定値は `Alt+Space` です。
- 他のアプリと衝突する場合は、別の組み合わせに変更してください。

### アップデートとサポート

- 「起動時に新しいバージョンがあるか確認する」: 既定でオンです。オフにすると、起動時の確認を行いません。
- 「今すぐ確認」: 新しいバージョンがあるかをすぐに確認します。
- 「ログフォルダを開く」: 不具合を報告するときは、このフォルダの `sagasu.log` を報告に添付してください。ログはパソコンの中だけに保存されます（最大約 2 MB で、古いものは自動的に入れ替わります）。

## 13. アップデート

起動してしばらくすると（約 8 秒後）、Sagasu は GitHub Releases に新しいバージョンがあるかを確認します。新しいバージョンがあると、画面下のステータスバーに青いボタン「新しいバージョン vX があります — 更新する」が表示されます。

ボタンを押すと、署名付きのインストーラーをダウンロードしてインストールし、Sagasu が再起動します。署名を検証するため、公式のビルド以外はインストールされません。

> v0.1.0 には自動アップデート機能がありません。v0.1.0 をお使いの方は、最新版のインストーラーを [Releases](https://github.com/Nishi-Yura/sagasu/releases) から一度手動でダウンロードしてインストールしてください。それ以降は自動で更新できます。

## 14. データの保存場所

- 検索インデックス: `%APPDATA%\jp.sagasu.app`
- ログ: 設定「アップデートとサポート」の「ログフォルダを開く」から開けます
- データ形式のバージョン: 設定画面の一番下に「データ形式 vN」として表示されます。将来のバージョンで既存のデータを安全に引き継ぐために使われます。現在はデータ形式 v3 です。以前のバージョンのデータは、起動時に自動で新しい形式に引き継がれます。ピン留めと履歴も残ります。
